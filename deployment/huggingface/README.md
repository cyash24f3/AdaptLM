Public research demo for [cyash24f3/AdaptLM](https://github.com/cyash24f3/AdaptLM).
Uses the genuine M5-trained Qwen2.5-1.5B-Instruct adapter and free ZeroGPU hardware.
No paid inference API, GPU upgrade, or billing credit is enabled. Visitor quotas apply.
Inputs leave the visitor's machine and are processed on Hugging Face infrastructure.
Use fictional messages. The app does not intentionally persist interactive inputs.
Dataset labels are independently semantically unreviewed. Invalid output is rejected.
The model card and preserved reports disclose substantial span and category failures.
